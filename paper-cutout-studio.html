Affinity Cutout Workflow
  1. Switch to Pixel Persona/Tab.
  2. Press W to select Selection Brush Tool (or switch within the W menu).
  3. Make selection and press Cmd + C to copy.
  4. Press Cmd + Shift + N to create a new layer and paste selection.
  5. Export as PNG using top-right export button.
